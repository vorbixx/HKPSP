# PSP button layout (user decision 4, 2026-11-14)

Rule: the Nintendo Switch version's defaults, by button position. Switch B/A/Y/X (bottom, right,
left, top) = PSP Cross/Circle/Square/Triangle; Switch shoulder actions go to L/R as closely as
possible.

## Switch defaults (source)

Source: Fextralife Hollow Knight wiki, Controls page, Switch column
(https://hollowknight.wiki.fextralife.com/Controls), read 2026-11-14. **One source only** [H]:
hollowknight.wiki returned HTTP 403, Nintendo's manual was not found, and other search hits
quoted the same page. The PC build has no Switch branch to read (InputHandler is not decompiled;
Switch code is compiled out of the PC player [H]). Team Cherry announced Switch rebinding with
Gods & Glory; the defaults below are the original 2018 ones.
Second-source search 2026-11-14 (nintendo.com game page, Team Cherry Switch patch post,
hollowknight.wiki 403, fandom 402, guide sites 403): no independent source found; every reachable
page repeats Fextralife. Remaining check: the in-game Controls screen on a Switch or a capture of it.

| Action | Switch | Position | PSP |
| --- | --- | --- | --- |
| Jump | B | bottom face | Cross |
| Attack | Y | left face | Square |
| Focus / Cast | A | right face | Circle |
| Dream Nail | X | top face | Triangle |
| Dash | ZR | right trigger | R |
| Super Dash | ZL | left trigger | L |
| Quick Cast | R | right shoulder | — (Circle tap casts, as in the original) |
| Quick Map | L | left shoulder | hold Select |
| Inventory | − | system | Select (tap) |
| Pause | + | system | Start |
| Move | stick / d-pad [H] | | analog nub and d-pad |
| Menu confirm / cancel | not in the source | | Circle confirm / Cross cancel |

## Decision (user 2026-11-14: accepted the proposal below)

The PSP has one shoulder per side; Switch has two. Proposal: the trigger actions (ZR Dash, ZL
Super Dash) take R/L because both are held in play; Quick Cast is dropped because a Circle tap
already casts (difference: the original Quick Cast skips the tap-release delay [H]); Quick Map
moves to holding Select, Inventory stays on a Select tap. Alternatives: L = Quick Map and Super
Dash = L+R, or a d-pad direction for Quick Map if movement uses only the nub. Menu confirm/cancel
by position would be Circle confirm / Cross cancel (Switch A/B) [H, source missing].
